# Magarr documentation

Magarr is a self-hosted magazine PVR, in the style of Sonarr and Radarr: it keeps a library of
magazines, finds new and missing issues on your Usenet or BitTorrent indexers, sends them to your
download client, and files the finished downloads under a consistent name.

2. [Getting started](getting-started.md): from an empty install to the first automatic grab

5. [Download clients](download-clients.md): SABnzbd, NZBGet, qBittorrent, Transmission, Deluge, rTorrent
6. [Importing](importing.md): how downloads become library files; manual import
